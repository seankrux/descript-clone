# Descript Companion — Manifest V3 Chrome Extension

This companion extension provides screen, webcam bubble, and tab audio recording with direct timeline sync to the Descript webapp.

## Features
- **Capture Modes**:
  - Screen + Floating Webcam Bubble
  - Active Tab Recording (with tab audio loopback)
  - Full Desktop Display
  - Camera-Only Mode
- **Audio Inputs**:
  - Crisp microphone capture + System / Tab audio mixing
- **Interactive In-Page HUD**:
  - Draggable circular webcam preview bubble (mirrored, resizeable)
  - Draggable bottom floating control pill (`● REC 00:15`, Pause, Resume, Finish, Discard)
- **Direct Descript Sync**:
  - One-click "Open in Descript Web Studio" button to import recorded media directly into the multi-track timeline and trigger AI transcription.

## Installation in Chrome / Chromium
1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** via the toggle switch in the top right corner.
3. Click the **Load unpacked** button in the top left corner.
4. Select this directory:
   `/Users/sean5/.gemini/antigravity/scratch/descript-clone/extension`
5. Click on the extension icon in your toolbar to start recording any tab or screen!
